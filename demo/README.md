## 주요 시연 내용

1. 성인의 프로그램 신청, 신청서 파일 첨부와 신청내역 확인
2. 만 14세 미만 신청 시 보호자 이름·추가 서명·동의 입력
3. 아동·보호자 동의자 표시와 추가 설문 작성·제출
4. 관리자 화면에서 아동·보호자의 동의 기록 확인
5. 기관 담당자의 프로그램 등록, 홍보지 자동입력, 설문 제작·연결
6. 최고관리자가 이용할 수 있는 관리 탭
7. Google Drive에 저장된 원본 신청서, 설문 응답 PDF와 CSV 명단 확인

사이트의 자체 제작 등대 아이콘과 새 보호자 동의 기능을 반영했습니다. 보호자 기본 동의 기록은 웹사이트에서 관리하며 Google Drive의 설문 신청서와 구분합니다. 보호자 서명 입력이 법정대리인의 신원·관계 확인 완료를 뜻하지는 않습니다.
