- 이용자: 기본 신청 / 설문 응답 / 첨부자료 제출로 분리했습니다.
- 직원: 홍보지 인식과 프로그램 등록 / 양식 업로드 / 설문 관리 / 신청자 관리로 분리했습니다.

- 목차별 색상, 큰 측면 자막, 마우스 포인터와 노란 클릭 효과를 적용했습니다.
- 1920×1080 MP4, 한국어 화면 설명, 배경음악 포함, 내레이션 없음.

## 촬영 기준

최신 v109 웹앱 소스를 별도의 녹화 환경에서 실행했습니다. 이름·연락처·기관·신청내역은 시연용 가상자료이며 로그인·저장·설문·홍보지 인식의 서버 응답은 녹화용으로 재현했습니다. 실제 운영 신청이나 Google Drive 저장의 성공을 검증하는 영상은 아닙니다. CSV 다운로드는 웹앱의 실제 다운로드 기능으로 가상 명단을 생성했습니다. 운영 사이트와 실제 신청 기록은 변경하지 않았습니다.
