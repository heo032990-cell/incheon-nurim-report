## 주요 시연 내용

1. 일반 이용자의 프로그램 신청과 신청내역 확인
2. 신청서 파일 첨부 및 추가 설문 작성
3. 기관 담당자의 프로그램 등록과 홍보지 내용 자동 입력
4. 최고관리자가 이용할 수 있는 관리 탭
5. Google Drive에 저장된 신청서와 명단 확인
