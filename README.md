## 이번에 바뀐 점

- 이용자: 기본 신청 / 설문 응답 / 첨부자료 제출로 분리했습니다.
- 직원: 홍보지 인식과 프로그램 등록 / 양식 업로드 / 설문 관리 / 신청자 관리 / Google 자료 확인으로 분리했습니다.
- 마지막에는 기존에 촬영한 Google Drive의 원본 신청서 PDF, 설문 응답 PDF, 신청명단 CSV 확인 장면을 추가했습니다.
- 배경음악은 영상 길이에 맞춰 반복하며, 음악 길이에 맞추기 위해 장면을 줄이지 않았습니다.
- 신청자 현황·상세 정보 확인과 참여 명단 CSV 다운로드를 웹앱 화면에서 보여줍니다.
- 목차별 색상, 큰 측면 자막, 마우스 포인터와 노란 클릭 효과를 적용했습니다.
- 1920×1080 MP4, 한국어 화면 설명, 배경음악 포함, 내레이션 없음.

## 촬영 기준

01~07편은 최신 v109 웹앱 소스를 별도의 녹화 환경에서 실행했습니다. 이름·연락처·기관·신청내역은 시연용 가상자료이며 로그인·저장·설문·홍보지 인식의 서버 응답은 녹화용으로 재현했습니다. CSV 다운로드는 웹앱의 실제 다운로드 기능으로 가상 명단을 생성했습니다.

08편은 2026-09-16에 촬영한 실제 Google Drive 확인 장면을 편집한 영상입니다. 시연용 가상 신청자료의 원본 PDF, 설문 응답 PDF, 신청명단 CSV를 보여줍니다. 이번 편집 과정에서는 운영 사이트와 실제 신청 기록을 변경하지 않았습니다.
