# 인천누림지도 · 제출자료

인천누림지도의 이용 방법을 화면과 단계별 설명으로 안내합니다.

## 화면 가이드

| 대상 | 가이드 | 주요 내용 |
| --- | --- | --- |
| 일반 이용자 | [이용자 가이드 보기](guides/USER-GUIDE.md) | 프로그램 검색·신청·파일 첨부·신청내역 조회 |
| 기관 관리자 | [관리자 가이드 보기](guides/ADMIN-GUIDE.md) | 프로그램 등록·설문 설정·신청자료 관리 |

각 링크를 누르면 이미지와 설명을 함께 볼 수 있습니다. 별도의 파일 다운로드는 필요하지 않습니다.

> 화면은 v104의 실제 화면 소스를 가상자료로 실행해 촬영했습니다. 실제 운영 신청·저장 기록이 아니며, 추가 설문 이미지는 미리보기입니다.


## 데모영상

[인천 누림지도 데모영상 보기](demo/README.md)

최신 v109 화면을 바탕으로 이용자 3편(기본 신청·설문 응답·자료 첨부)과 직원 4편(홍보지 인식·양식 업로드·설문 관리·신청자 관리)을 제공합니다. 큰 측면 자막, 클릭 효과, 이용자 Buddy·직원 Sunny 배경음악을 적용했습니다. 전체 영상은 약 4분 51초입니다. 가상자료와 촬영용 서버 응답으로 구성한 이용 안내이며, 실제 운영 저장 검증 영상은 아닙니다.
